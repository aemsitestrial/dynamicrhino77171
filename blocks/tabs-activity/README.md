# tabs-activity

Custom **tabs** block. Purpose: activity-article-tabs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: cell 1 = tab label; cell 2 = rich text holding repeated articles (image, tag paragraph, H3 with link, description paragraph), decorated into a 3-up card grid.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
